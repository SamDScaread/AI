# 角色 3D 模型放这里（支持多模型）

把 `.glb` 模型文件放进本目录，并在 **`manifest.json`** 里登记一条记录，刷新游戏即会用它替换占位的几何体小人。
不登记任何模型时，游戏沿用内置的几何体角色，一切照常（控制台也不会报错）。

## 怎么加一个模型
1. 把模型文件（如 `alice.glb`）放进 `assets/models/`。
2. 打开 `manifest.json`，在 `characters` 里加一条：
   ```json
   { "key": "alice", "name": "爱丽丝", "file": "alice.glb", "role": "opponent" }
   ```
3. 刷新游戏。`role: "opponent"` 的那条会显示在对面席位（单机对手）。

> 多个模型都可以登记。`role` 取值：`opponent`=对面对手（单机默认显示这条；没有标 opponent 就用第一条）；`you`=你自己（用于联机时展示给对方，目前先登记备用）；其余可填 `any`。

## 可选微调字段（写在每条记录里）
- `scale`：整体放大系数，`1` = 自动适配到默认身高。偏大/偏小就调这个。
- `rotY`：朝向（弧度）。模型若**背对**镜头填 `3.14159`，侧对填 `1.5708`。
- `yOffset`：上下偏移（正数抬高）。
- `targetH`：目标身高（单位，默认 3.4）。

## 模型要求
- **格式 `.glb`**（单文件、内嵌贴图最省事）。
- **不要 Draco / Meshopt / KTX2 压缩**：否则解析失败会回退占位角色，请用未压缩 `.glb` 重新导出。
- 朝向尽量**面朝 +Z**（朝镜头）；不对就用 `rotY` 修正。
- 自带动画（如 idle）会自动播放第一条。

## 版权 / 隐私
只使用你**有权使用**的模型：自己/朋友制作的、本人同意的、或 CC0 / CC-BY 等开放协议的。
**请勿**直接使用《赛博朋克 2077》等游戏里的角色文件。涉及真人形象请确保本人同意，且不要在文件/记录里夹带电话号码等个人信息。
