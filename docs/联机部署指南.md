# 《气闸孤注：γ-7》联机部署保姆级指南

联机需要一台**一直开着的服务器**来转发双方的操作。本游戏的服务器是**纯 Node、零依赖**
（`server/server.mjs`），随便一个能跑 Node 的地方都能托管。下面用最省事、**不用绑信用卡**
的 [Render](https://render.com) 免费方案，一步步来。

> 关键概念：**游戏页面**（`deepspace.html`，谁都能打开）和**对战服务器**（转发消息）是两样东西。
> 你只需要把**服务器**部署到云上拿到一个网址，玩家在游戏里填这个网址就能联机。

---

## 方案 A · Render 免费托管（推荐，不用绑卡）

### 1. 把代码放到 GitHub
本仓库 `SamDScaread/AI` 已经在 GitHub 上了——这一步你已经完成 ✅。

### 2. 在 Render 新建 Web Service
1. 打开 <https://render.com>，用 GitHub 账号登录。
2. 右上角 **New +** → **Web Service**。
3. 选择并授权连接你的仓库 `SamDScaread/AI`。
4. 填写配置：
   | 项 | 填什么 |
   |---|---|
   | **Name** | 随便起，比如 `deepspace` |
   | **Region** | 选离你最近的（如 Singapore） |
   | **Branch** | `main`（或当前功能分支） |
   | **Root Directory** | 留空 |
   | **Runtime** | `Node` |
   | **Build Command** | 留空（本项目零依赖，不需要构建） |
   | **Start Command** | `node server/server.mjs` |
   | **Instance Type** | **Free** |
   | **Health Check Path** | `/healthz`（可选，服务器已内置） |
5. 点 **Create Web Service**，等状态变成 **Live**（约 1–2 分钟）。
6. 页面顶部会给你一个网址，形如 `https://deepspace-xxxx.onrender.com`。**记下它。**

### 3. 在游戏里连上服务器
1. 打开游戏 → 主菜单 → **联机模式**。
2. **服务器地址** 填：
   ```
   wss://deepspace-xxxx.onrender.com
   ```
   ⚠️ 一定是 **`wss://`**（带两个 s），不是 `ws://`——因为 Render 用的是 https，必须用加密的 wss。
3. 一人点 **创建房间**，把 4 位房号发给对手；对手填**同一个服务器地址** + 房号点 **加入**。
4. 对手点 **准备**，房主点 **开始对决**——开打！

## 常见问题

- **第一次连很久 / 连不上？** 免费实例闲置约 15 分钟会休眠，被唤醒要 ~30–60 秒。多等一会、或先打开
  `https://deepspace-xxxx.onrender.com/healthz`（看到 `ok` 就说明醒了）再回游戏点创建。
- **`ws://` 还是 `wss://`？** 本地自己测用 `ws://localhost:3001`；云端（https 网址）一律 `wss://`。
- **房间会保存吗？** 不会。房间只存在服务器内存里，服务器重启/休眠后房间消失，重新创建即可。
- **够几个人玩？** 这游戏是 1v1，免费档完全够你和朋友玩。想更稳定（不休眠）可升级 Render 付费档（约 $7/月）。

## 玩家从哪儿打开游戏页面？

对战服务器搞定后，玩家还需要能打开 `deepspace.html`。三选一：

1. **各自本地运行**（最简单的测试）：在仓库目录执行 `npm start`，浏览器开 `http://localhost:8080/deepspace.html`。
2. **托管静态页面**（让朋友直接点链接玩）：把仓库部署到 **GitHub Pages** 或 **Netlify**（都免费、拖拽即可），
   朋友打开你的页面网址，再在联机里填上面那个 `wss://...` 服务器地址即可。
3. **同一台服务器也托管页面**：需要少量改动让 `server.mjs` 兼做静态服务——需要的话我可以帮你加。

## 方案 B · 其他平台（简述）

- **Railway / Fly.io**：同样跑 `node server/server.mjs`，监听 `process.env.PORT`。需要绑卡，有免费额度。
- **自己的 VPS（如阿里云/腾讯云轻量）**：装好 Node 后 `PORT=3001 node server/server.mjs`；
  若要 `wss://` 需用 Nginx/Caddy 反代并配 TLS 证书。需要我可以给配置样例。

> 任何平台只要满足两点即可：① 能跑 Node；② 把外部端口接到 `process.env.PORT`。服务器已内置
> `/healthz` 健康检查和 WebSocket 升级，开箱即用。
