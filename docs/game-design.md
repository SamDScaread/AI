## 1. 设定 / Setting

一座被遗弃的深空中转站「**γ-7 气闸厅**」。补给耗尽，幸存者用一把改装过的**脉冲钉枪**
（弹仓里混着**实芯弹**和**空包弹**）对赌氧气配额。霓虹故障、警报红光、金属回声——
赛博朋克底色。

- **对局人数**：先做**1v1 决斗**（最稳、最经典）。框架支持 2–8 人，二期可扩展为"乱斗/淘汰赛"。
- **对手**：支持 **真人 vs 真人**（联机）。是否再加一个 **AI「仲裁者」** 供单人练习，二期再说。

## 2. 核心回合 / Core loop

每一**轮**开始时，弹仓被装入若干发弹，**实/空数量当众公布、但具体顺序打乱且只有服务器知道**：

- 例：本轮装 5 发 = **2 实芯 + 3 空包**（顺序随机、隐藏）。
- 轮到你时，你可以：
  1. **朝对手开枪**：实芯 → 对手扣血；空包 → 无事。**无论实空，回合都交给对手。**
  2. **朝自己开枪**：空包 → 安全，**回合仍归你**（可连续行动）；实芯 → 自己扣血，回合交给对手。
- 打掉一发，弹仓少一发。**弹仓打空 → 重新装填新一轮**（实/空数量重新随机公布），继续直到分胜负。

> `viewFor` 会保证：弹仓里"下一发到底是实是空"客户端**永远拿不到**，只有用「扫描仪」道具
> 时服务器才单独告诉那一个玩家——天生防作弊。

## 3. 血量与胜负 / HP & win

- 每人初始 **血量 = 4**（建议范围 2–6；越低越快越刺激）。我的想法是最开始的回合也就是第一局每人都有四滴血，扣完即第一回合败北，第二回合开始每人有三滴血，第三回合也就是决胜局，没人来到两滴血，这样才紧张刺激。
- 谁的血量先归 **0**，对手获胜。
- 除此之外，我还想设置这么一个额外玩法，三局打完，赢家可以选择给对面“怜悯”，让其可以复活到场上进行最后决战，如果给怜悯方仍然赢下，则可以获得双倍奖赏，如果失败不仅不能获得任何奖赏还会获得双倍惩罚。

## 4. 道具系统 / Items

每轮装填时，给双方**各随机发 1–2 个**道具（默认每轮发 1 个，手上最多持有 4 个）。
我希望在最开始的第一局不需要太多道具，而且只给最简单的查看道具（扫描仪）和双倍伤害道具（过载芯）即可，随着游戏进程可以给更多的数量的道具和更多种类的道具，决胜局和怜悯局将会开放最多的种类和数量的道具，拉高游戏胜负的不确定性，究竟是胜方获得双倍还是濒死者绝境翻盘。
默认道具表（原创命名，效果是通用机制）：


| 道具 | 效果 |
|---|---|
| 🩹 **万宝路牌香烟(Marlboro Tobacco)** | 立即回 1 点血（不超过上限） |
| 🔍 **扫描仪 (Scanner)** | 偷看"当前这一发"是实是空（只有你看到） |
| ⏏️ **退弹器 (Ejector)** | 把当前这一发弹退掉、不开枪（用来甩掉一发实弹） |
| 🔒 **磁锁 (Maglock)** | 跳过对手的下一个回合 |
| ⚡ **过载芯 (Overload)** | 本回合这一枪若命中，伤害 ×2 |

> 道具数量/种类/概率都可调。想加新道具（比如"偷对手一个道具""把实弹变空弹"）直接在这里写。
> 目前想不到更多的道具了，先这样，后期再改动

## 5. 一局流程 / Flow

```
进房 → 准备 → 开局
  └─ 装填第 1 轮（公布实/空数量，发道具）
       └─ 轮流行动（开枪 / 用道具）直到弹仓打空
  └─ 装填第 2 轮 …（循环）
继续直到某人血量=0 → 结算胜负
```

- `deepspace.html`（默认）：Three.js 渲染的**深空气闸厅体素场景**——两名体素决斗者、桌上的枪
